Each `YYYY-MM-DD.tar.gz` is a compressed copy of the original
`nfl-props/data/snapshots/YYYY-MM-DD/` directory of per-event JSON
line captures. Unpack with `tar -xzf YYYY-MM-DD.tar.gz`.
Loose files in this folder (e.g. capture_log.jsonl, possibly gzipped)
were copied from the same source directory.
